## About Me

I'm a **Full-Stack Developer** focused on building practical web applications, backend services, and cross-platform mobile experiences. I enjoy working across the stack — from designing interfaces and integrating APIs to structuring backend logic and database access.

- **Web:** Modern frontend applications and admin dashboards
- **Backend:** REST APIs, authentication, authorization, and database-driven systems
- **Mobile:** Kotlin Multiplatform and Compose Multiplatform
- **Engineering interests:** Software architecture, maintainable code, and clear API design

I'm continuously improving my engineering skills and looking for opportunities to contribute to real-world software products.
